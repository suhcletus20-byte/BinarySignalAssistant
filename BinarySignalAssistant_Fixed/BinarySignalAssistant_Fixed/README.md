# Binary Signal Assistant

Binary Options Signal Assistant for Quotex — 100% compliant display-only overlay.

## Download APK

Go to **Actions** tab → Click latest workflow run → Download `app-debug` artifact.

## Features

- 5 SMC Strategies (Liquidity Sweep, Order Block, FVG, Breaker Block, Inducement)
- OTC Market Detection
- Session Time Filters
- Multi-Asset Monitoring
- Win Rate ML Tracking
- Push Notifications

## Disclaimer

This app provides analytical signals only. It does NOT connect to, interact with, or trade on any broker platform. All trading decisions are your sole responsibility.
